# 🩺 Diabetes Classification using Machine Learning

## 📌 Overview
This project focuses on predicting whether a person is diabetic or not using machine learning techniques.  
It uses medical attributes such as glucose level, BMI, age, and other health indicators to build a classification model.

Machine learning models are widely used in healthcare to improve early diagnosis and decision-making. :contentReference[oaicite:1]{index=1}

---

## 🎯 Objective
- To build a classification model for diabetes prediction  
- To perform data preprocessing and analysis  
- To evaluate model performance using appropriate metrics  

---

## 📊 Dataset
- The dataset contains medical features like:
  - Pregnancies  
  - Glucose  
  - Blood Pressure  
  - BMI  
  - Age  
- Target variable:
  - `Outcome` (0 → Non-diabetic, 1 → Diabetic)
